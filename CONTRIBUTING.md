# Contributing

Thanks for your interest in improving English Language Corner.

## How to contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-idea`)
3. Make your changes in `index.html` (single-file app)
4. Test in both light and dark mode, and on mobile widths
5. Commit with a clear message
6. Open a pull request against `main`

## Guidelines

- Keep the project dependency-free (HTML, CSS, vanilla JS only)
- Preserve existing section IDs used for navigation anchors
- Respect `prefers-reduced-motion`
- Maintain accessible focus states and ARIA labels
- Do not invent statistics or fake testimonials

## Questions

Open an issue if something is unclear. Happy to help.
