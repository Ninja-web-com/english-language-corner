# Deployment

This project is a single static file. You can host it anywhere.

## Options

- **GitHub Pages** — enable Pages on the `main` branch, root folder
- **Netlify** — drag-and-drop the folder or connect the repo
- **Vercel** — import the repo; no build command needed
- **Cloudflare Pages** — same idea, static output

## GitHub Pages (quick)

1. Repo Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / root
4. Save — site will be at `https://ninja-web-com.github.io/english-language-corner/`

No build step. Point the host at `index.html`.
