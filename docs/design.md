# Design system

## Colors

- Deep navy / indigo backgrounds
- Electric purple and cyan accents
- Soft glows and layered gradients

## Typography

- **Sora** — display headings
- **DM Sans** — body and UI

## Motion

- Theme toggle: crossfade + rotate (0.35s)
- Scroll: `scroll-behavior: smooth`
- Cards and sections: staggered reveal on viewport entry
- Button press: subtle scale on `:active`
